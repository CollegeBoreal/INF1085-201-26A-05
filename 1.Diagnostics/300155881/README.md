# 🖥️ Démontage et remontage d'un serveur HP ProLiant DL360 G6

**Étudiante :** Fairouz Sadoun
**Matricule :** 300155881
**Programme :** Techniques des systèmes informatiques
**Module :** INF1085 – Administration Linux

## 🎯 Objectif du laboratoire

L'objectif de ce laboratoire est de démonter,
identifier et remonter les principaux composants
matériels d'un serveur HP ProLiant DL360 G6.

Ce laboratoire permet également de vérifier
la détection des processeurs et de la mémoire
dans le BIOS, puis d'étudier la configuration
des disques avec le contrôleur RAID.
