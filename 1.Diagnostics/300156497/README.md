# Configuration du serveur HP ProLiant DL360 G6
![images alt](https://github.com/CollegeBoreal/INF1085-201-26A-05/blob/main/1.Diagnostics/300156497/images/0a5d22d4-ba33-49df-8a22-de06ffa339c3.jpeg?raw=true) Cette image montre l’intérieur du serveur HP ProLiant DL360 G6. On y observe plusieurs barrettes de mémoire RAM ainsi que le dissipateur thermique du processeur, qui assurent les performances et le bon fonctionnement du serveur.
![images alt](https://github.com/CollegeBoreal/INF1085-201-26A-05/blob/main/1.Diagnostics/300156497/images/4306a99c-76ac-4aeb-b926-6f0bfb003784.jpeg?raw=true) Cette image montre l’écran de configuration du contrôleur HP Smart Array P410i du serveur HP ProLiant DL360 G6. On y voit la création d’un volume logique de 273,4 Go en RAID 5, ainsi que l’option permettant d’enregistrer la configuration du stockage avant le démarrage du serveur.
![images alt](https://github.com/CollegeBoreal/INF1085-201-26A-05/blob/main/1.Diagnostics/300156497/images/8dfcbe95-c2dd-422e-95bd-dd4cd1700de8.jpeg?raw=true) Cette image montre un message d’avertissement du contrôleur HP Smart Array P410i lors de la configuration du serveur HP ProLiant DL360 G6. Le système détecte un déplacement invalide de disque pendant le démarrage (POST) et avertit que toute modification de la configuration pourrait entraîner la perte des informations de l’ancien volume logique.
![images alt](https://github.com/CollegeBoreal/INF1085-201-26A-05/blob/main/1.Diagnostics/300156497/images/9427c2f4-776e-48d6-b46f-130f0e189fd2.jpeg?raw=true) Cette image montre l’écran de démarrage du serveur HP ProLiant DL360 G6. On y voit le contrôleur HP Smart Array P410i signaler que les disques ont changé de position et que la configuration du volume RAID doit être vérifiée. Le système recommande également une mise à jour du micrologiciel (firmware) des disques avant de poursuivre la configuration.
![images alt](https://github.com/CollegeBoreal/INF1085-201-26A-05/blob/main/1.Diagnostics/300156497/images/c2cb620f-8b42-43cd-a64a-4bd295b81138.jpeg?raw=true) Cette image montre le serveur HP ProLiant DL360 G6 ouvert avec son capot retiré. Le capot contient les schémas et instructions de maintenance du serveur, tandis que les câbles d’alimentation et VGA sont connectés à l’arrière pour permettre la configuration et les tests du système.
![images alt](https://github.com/CollegeBoreal/INF1085-201-26A-05/blob/main/1.Diagnostics/300156497/images/e141e997-d84b-4698-9439-b49b95fa9cbd.jpeg?raw=true) Cette image montre l’utilitaire de configuration du contrôleur HP Smart Array P410i du serveur HP ProLiant DL360 G6. Les trois disques SAS de 146,8 Go sont sélectionnés pour créer un volume RAID 5, offrant un compromis entre capacité de stockage, performance et tolérance aux pannes.
![images alt](https://github.com/CollegeBoreal/INF1085-201-26A-05/blob/main/1.Diagnostics/300156497/images/e7eac604-9f9c-4b52-a965-2d4592187f6c.jpeg?raw=true) Cette image montre l’utilitaire de configuration BIOS du serveur HP ProLiant DL360 G6. On y voit les paramètres système, les options de démarrage, la gestion de l’alimentation ainsi que les informations matérielles du serveur, notamment la mémoire installée (8192 Mo) et le processeur Intel configuré.
